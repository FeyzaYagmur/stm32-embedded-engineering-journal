# GPIO DC Motor Actuator Interfacing & Relay Control

This project demonstrates how to interface and control external electromechanical inductive loads, specifically a DC motor/vibrational actuator, using a general-purpose output pin (GPIO) from an STM32 microcontroller. It highlights the baseline concepts of driving higher-current peripheral loads via output switching transistors or driver modules.

##  Hardware & Configuration
- **MCU:** STM32F407VGT6 (ARM Cortex-M4)
- **Actuator Component:** 3V-5V Mini DC Motor / Vibration Actuator
- **Driving Interface:** Transistor Switching Circuit (NPN/MOSFET with Flyback Diode) / Relay Module
- **Active Pins:** `PB0` (Actuator Control Output Pin)
- **Method:** Periodic Digital Power Switching via `HAL_GPIO_WritePin()`

##  Key Concepts Covered
- **Electromechanical Actuator Interfacing:** Interfacing inductive DC loads to microcontroller GPIOs safely via switching transistor/driver interfaces.
- **Inductive Load Protection:** Understanding flyback diode integration to suppress back-EMF voltage spikes generated by switching motor coils.
- **Time-Sequenced Power Control:** Generating non-PWM periodic ON/OFF active-state intervals ($2000\text{ms}$ running / $2000\text{ms}$ idle) for hardware power stage verification.

##  Complete Source Code (`main.c` & GPIO Init)

Below is the complete C implementation written in STM32CubeIDE using native HAL drivers:

```c
#include "main.h"

/* GPIO Initialization Function */
static void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  /* Enable GPIOB Clock */
  __HAL_RCC_GPIOB_CLK_ENABLE();

  /* Set initial pin state to LOW */
  HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET);

  /* Configure GPIOB Pin 0 as Push-Pull Output */
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOB, &GPIO_InitStruct);
}

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* Turn ON DC Motor Driver (Set PB0 HIGH for 2 seconds) */
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);
    HAL_Delay(2000);

    /* Turn OFF DC Motor Driver (Set PB0 LOW for 2 seconds) */
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET);
    HAL_Delay(2000);

    /* USER CODE END WHILE */
  }
}
