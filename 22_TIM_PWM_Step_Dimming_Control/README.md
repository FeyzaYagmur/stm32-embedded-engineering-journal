# Timer PWM Discrete Step Dimming Control

This project explores analog-like power output control using Pulse Width Modulation (PWM) generated by the General-Purpose Timer 4 (TIM4) peripheral. By dynamically updating the Capture/Compare Register (CCR) value using the `__HAL_TIM_SET_COMPARE()` macro, the firmware alternates the duty cycle across predefined discrete thresholds (`100`, `300`, `600`, `1000`), stepping through different LED brightness levels.

## ⚙️ Hardware & Configuration
- **MCU:** STM32F407VGT6 (ARM Cortex-M4)
- **Peripherals Used:** TIM4 (Channel 1 PWM Mode), Onboard LED
- **Active Pins:** `PD12` (TIM4_CH1 Output Pin)
- **Method:** Discrete Duty Cycle Modulation via `__HAL_TIM_SET_COMPARE()`

## 🔍 Key Concepts Covered
- **Pulse Width Modulation (PWM):** Generating variable duty cycle square waves at constant frequencies to control average power delivered to output peripherals.
- **Compare Register Manipulation:** Directly configuring the Capture/Compare Register (CCR1) dynamically during loop execution to alter pulse widths.
- **Discrete Brightness Stepping:** Evaluating power output scaling by stepping through sequential duty cycle values ($10\%, 30\%, 60\%, 100\%$) with controlled delay intervals.

## 💻 Complete Source Code (`main.c` & TIM4 PWM Init)

Below is the complete C implementation written in STM32CubeIDE using native HAL drivers:

```c
#include "main.h"

TIM_HandleTypeDef htim4;

/* TIM4 Peripheral Initialization Function */
static void MX_TIM4_Init(void)
{
  TIM_MasterConfigTypeDef sMasterConfig = {0};
  TIM_OC_InitTypeDef sConfigOC = {0};

  htim4.Instance = TIM4;
  htim4.Init.Prescaler = 83;             // Scale timer clock for PWM frequency
  htim4.Init.CounterMode = TIM_COUNTERMODE_UP;
  htim4.Init.Period = 999;               // ARR value (1000 total clock ticks per cycle)
  htim4.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
  htim4.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_DISABLE;
  HAL_TIM_PWM_Init(&htim4);

  sMasterConfig.MasterOutputTrigger = TIM_TRGO_RESET;
  sMasterConfig.MasterSlaveMode = TIM_MASTERSLAVEMODE_DISABLE;
  HAL_TIMEx_MasterConfigSynchronization(&htim4, &sMasterConfig);

  /* Configure PWM Channel 1 */
  sConfigOC.OCMode = TIM_OCMODE_PWM1;
  sConfigOC.Pulse = 0;                   // Initial Compare value
  sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
  sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;
  HAL_TIM_PWM_ConfigChannel(&htim4, &sConfigOC, TIM_CHANNEL_1);
}

/* GPIO Initialization Function */
static void MX_GPIO_Init(void)
{
  __HAL_RCC_GPIOH_CLK_ENABLE();
  __HAL_RCC_GPIOD_CLK_ENABLE();
}

/* Infinite Loop inside main() */
int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();
  MX_TIM4_Init();

  /* Start TIM4 PWM Output on Channel 1 */
  HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* Step 1: 10% Duty Cycle (Dim) */
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 100);
    HAL_Delay(500);

    /* Step 2: 30% Duty Cycle */
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 300);
    HAL_Delay(500);

    /* Step 3: 60% Duty Cycle */
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 600);
    HAL_Delay(500);

    /* Step 4: 100% Duty Cycle (Full Brightness) */
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 1000);
    HAL_Delay(500);

    /* USER CODE END WHILE */
  }
}
