# HC-SR04 Ultrasonic Sensor Proximity Threshold & Output Logic Control

This project implements a proximity threshold control system using an **HC-SR04 Ultrasonic Distance Sensor** interfaced with an STM32 microcontroller. Based on real-time distance calculations, when an object moves closer than a critical $5.0\text{cm}$ threshold ($Distance < 5.0\text{cm}$), the firmware triggers a designated GPIO digital output pin (`PB0`) to interface with external indicators (LED/Alarm) or actuators.

## ⚙️ Hardware & Configuration
- **MCU:** STM32F407VGT6 (ARM Cortex-M4)
- **Sensor Component:** HC-SR04 Ultrasonic Ranging Module
- **Active Pins:** `PA1` (Trig Output Pin), `PA0` (Echo Input Pin), `PB0` (Proximity Indicator Output Pin)
- **Method:** Dynamic Software Microsecond Delay (`delayUS`) & Proximity Threshold Switching
- **Trigger Condition:** Output `PB0` set to `HIGH` when $Distance < 5.0\text{cm}$

## 🔍 Key Concepts Covered
- **Transducer Physical Acoustics:** Observing high-frequency mechanical transducer vibration pulses generated by HC-SR04 sound emitters during active ranging cycles.
- **Closed-Loop Threshold Decision Logic:** Comparing dynamic floating-point distance measurements against hardcoded boundary conditions ($5.0\text{cm}$) to toggle digital output states (`GPIO_PIN_SET` / `GPIO_PIN_RESET`).
- **Modular Software Microsecond Timing:** Utilizing assembly instruction cycle routines (`__NOP()`) inside `delayUS()` to maintain precise $10\mu\text{s}$ trigger pulses without extra hardware timers.

## 💻 Complete Source Code (`main.c` / Defterdeki Yapı ile Birebir)

Below is the complete C implementation written in STM32CubeIDE using native HAL drivers:

```c
#include "main.h"

uint32_t echo_time = 0;
float distance = 0.0f;

/* Software Microsecond Delay using Assembly NOP Instruction */
void delayUS(uint32_t us)
{
  uint32_t count = us * 8;
  while (count--)
  {
    __NOP();
  }
}

/* Modular HC-SR04 Ultrasonic Sensor Driver Function */
float HCSR04_Read(void)
{
  uint32_t local_time = 0;
  float tempDistance = 0.0f;

  /* Step 1: Send 10us HIGH pulse to Trigger Pin (PA1) */
  HAL_GPIO_WritePin(GPIOA, GPIO_PIN_1, GPIO_PIN_RESET);
  delayUS(2);
  HAL_GPIO_WritePin(GPIOA, GPIO_PIN_1, GPIO_PIN_SET);
  delayUS(10);
  HAL_GPIO_WritePin(GPIOA, GPIO_PIN_1, GPIO_PIN_RESET);

  /* Step 2: Measure Echo Pin (PA0) pulse duration */
  while (!HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0));
  while (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0))
  {
    local_time++;
    delayUS(2);
  }

  /* Step 3: Convert Echo duration to centimeters */
  tempDistance = (float)local_time / 58.0f;

  return tempDistance;
}

/* GPIO Initialization Function */
static void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  __HAL_RCC_GPIOA_CLK_ENABLE();
  __HAL_RCC_GPIOB_CLK_ENABLE();

  /* Configure PA1 as Trigger Output */
  GPIO_InitStruct.Pin = GPIO_PIN_1;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

  /* Configure PA0 as Echo Input */
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

  /* Configure PB0 as Proximity Output (LED / Indicator) */
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOB, &GPIO_InitStruct);
}

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* Read distance from ultrasonic sensor */
    distance = HCSR04_Read();

    /* Proximity Condition: Trigger PB0 output if distance < 5cm */
    if (distance < 5.0f)
    {
      HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);   // Turn ON Output
    }
    else
    {
      HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET); // Turn OFF Output
    }

    HAL_Delay(100);

    /* USER CODE END WHILE */
  }
}
